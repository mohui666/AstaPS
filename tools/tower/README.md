# MGC 深渊战斗资源生成

在服务端根目录执行：

```powershell
python tools/tower/generate_current_abyss.py --resources resources --schedule-id 124
```

输入为本机资源包的 TowerSchedule、TowerFloor、TowerLevel、Dungeon、Monster、MonsterDescribe 和被引用的 MonsterPreview JSON。PT18 需先从自己的官方客户端导出并解码，不随此工具分发。

敌人种类、等级来自实际预览；每种一只、最多三只同时在场，分波、坐标和战斗流程由 MGC 编写。输出保留现有场景文件，只补 `resources/Scripts/Scene/` 下的 block/group。已有非本工具脚本会拒绝覆盖。怪物变体选择和各波站位写入同目录 `mgc-schedule-124.json`。

重复执行会覆盖仍保留首行生成标记的文件，不检查其内容是否被人工修改。需要手工编辑时先删掉首行 `-- Generated by MGC ...`，生成器便会拒绝覆盖该文件。

普通房复用现有深渊的 175/176 工作台、197/198 挑战、剩余时间与换队流程。11-1 以 188 守护挑战保留同一镇石（group `233899003`、config `3024`），使用原始 20/40/60% 星级条件。上下半场始终留在同一副本场景；该实现不声称复原官方数量、波次或站位。
