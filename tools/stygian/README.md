# MGC 幽境独立战场

在游戏 GM 聊天中执行 `/stygian <难度> <战场>`，例如 `/stygian 3 1`。控制台可使用 `stygian @1 3 1` 指定自己的在线角色。难度为 1–6，战场为 1–3；须先退出当前秘境和联机。

当前资源期数为 5269012。三个战场分别使用当期的矮灵雕刻师、秘源机兵·统御械和游雪的护刃，在原生场景 30002–30004 中单独开打；六档等级为 40、70、90、100、105、110，前三档每战限时 600 秒，后三档 120 秒。敌人、等级和限时参考[原神 Wiki 的 7.1 幽境资料](https://wikiwiki.jp/genshinwiki/幽境の激戦)，并与本机 LeyLineLevel 表核对。

这是 MGC 独立战场入口。原生活动页的按钮、三队编成、跨战场角色/装备限制、多人模式、官方成绩和奖励尚未恢复。怪物使用客户端已有变体和成长曲线；各档额外官方血量倍率、完整特殊机制尚未核实，不能宣称官服难度复刻。独立战场会提供真实倒计时、伤害、死亡和副本成功/失败流程，不向官方成绩或活动奖励数据写入结果。

实现位于 `LeyLineChallengeEnterFlow`、`LeyLineChallengeRun` 和 `StygianCommand`。现有永久玩法 5269 保留，已移除的限时活动不重新开放。

活动类型已根据本机 7.1 客户端枚举确认为 `NEW_ACTIVITY_LEY_LINE_CHALLENGE = 5701`；早期保存为类型 0 的 5269 配置会在读取时纠正，保留原排期和玩家进度。活动开放状态与原生页面开战属于不同环节，原生详情和进入请求尚未接通，不能将排期开放标为原生玩法已恢复。

`/stygian entrance`（控制台 `stygian @1 entrance`）只启用目标角色的幽境开放状态 4601 与场景 3 的入口点 1628，并刷新原生入口装置 73051004。入口坐标为 `(980.627, 260.567, -194.518)`；此操作不完成前置任务，不解锁其他地图点，也不把入口改成独立战场按钮。原生三队开战协议仍待接通。
